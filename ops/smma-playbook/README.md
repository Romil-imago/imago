# Imago Growth OS — BMAD Delivery Hub

This directory is the product and operating source of truth.

## BMAD lifecycle
1. Brief / product strategy — segment, offer, outcomes and assumptions.
2. PRD — user journeys, requirements, constraints and acceptance criteria.
3. Architecture — components, data, integrations, security and operations.
4. Epics and stories — thin, testable increments with dependencies.
5. Implementation — one vertical slice at a time.
6. Review — verify full flows, document decisions and update backlog.

## Release 0.1
Agency growth-audit intake, homeowner funnel demo, deterministic qualification scoring, consent capture, development JSONL logging, optional HTTPS GHL webhook and illustrative operations dashboard.

## Explicit non-goals
No autonomous cold outreach, SMS/email sending, ad publishing or budget changes, money movement, contract execution or live AI-agent actions. These need provider credentials, client approvals, policy checks, audit trails and kill switches.

## Documents
- product-brief.md — business vision and beachhead

- architecture.md — runtime/data/integration decisions
